# **App Name**: KeuanganKu

## Core Features:

- Expense Input: Manually input expense details with category and amount.
- CSV Expense Upload: Upload expense data via CSV files. Only accept the expense amount and expense name.
- Language Toggle: Switch the UI language between Bahasa Indonesia and English.
- Dark Mode Toggle: Switch between light and dark UI modes.
- File Type Detection: Use AI to recognize which columns represent values if user specifies file/pdf/image without specifying the specific fields.

## Style Guidelines:

- Primary color: Soft teal (#74b49b) for a calming financial overview.
- Background color: Light, desaturated teal (#e0f4f1).
- Accent color: Muted green (#5d9a7e), providing subtle highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth or personality.
- Use clean, minimalist icons representing different expense categories.
- Clean and intuitive layout for easy expense tracking. A prominent display of main metrics is helpful.
- Subtle transitions and animations on data updates to provide feedback and a modern feel.
